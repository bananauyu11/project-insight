# Project Insight — プロジェクト課題発見ナレッジ基盤

大規模ITプロジェクトの **成果物**・**成果物チェック観点**・**横断的な課題発見観点** を体系的に蓄積し、課題・リスク・改善機会の発見に活用するための Web アプリです。

- Next.js (App Router) / React / TypeScript
- データはブラウザ内（localStorage）に保存し、サーバーには送信しません
- CSV によるインポート・エクスポートでデータの移行・バックアップを行います

## 使い方

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # CSV・データモデルのテスト
npm run typecheck
npm run build
```

初回はホーム画面の「サンプルデータを読み込む」で動作を確認できます。

### Vercel へのデプロイ

リポジトリを Vercel にインポートするだけでデプロイできます（Framework Preset: Next.js、追加の環境変数は不要）。

## 画面

| パス | 内容 |
|---|---|
| `/` | ホーム（件数、横断検索、サンプル読み込み） |
| `/deliverables` `/checks` `/cross` | 一覧（キーワード・分類・工程・タグ・対象成果物・情報源で絞り込み、検索結果のCSV出力） |
| `…/view?id=ID` | 詳細（関連データへのリンク、削除） |
| `…/edit` `…/edit?id=ID` | 新規追加・編集 |
| `/csv` | CSVインポート（プレビュー・検証・追加/更新/スキップ選択・全件置換）、エクスポート、データ初期化 |

絞り込み条件は URL に反映されるため、ブックマークや共有ができます。

## データモデル

項目定義は `src/lib/schema.ts` に集約しており、フォーム・詳細表示・CSV 列構成はすべてここから生成されます。

| データ種別 | ID列 | CSVファイル |
|---|---|---|
| 成果物カタログ | `deliverable_id` | `deliverables.csv` |
| 成果物チェック観点 | `viewpoint_id` | `deliverable_checks.csv` |
| 横断的な課題発見観点 | `cross_viewpoint_id` | `cross_cutting.csv` |

関連付け:

- 成果物 `outputs_to` → 成果物、`related_viewpoint_ids` → チェック観点
- チェック観点 `target_deliverable_ids` → 成果物
- 成果物 `inputs` は自由記述。登録済みの成果物IDと一致する値はリンクとして扱います
- 成果物とチェック観点の関連は、どちら側に登録しても双方の詳細画面に表示されます
- データ削除時は、他データからの参照も自動的に解除されます（削除前に参照元を表示）

## CSV 仕様（スキーマバージョン 1）

- UTF-8（BOM 付き）で出力。取り込みは UTF-8（BOM 有無とも）を標準とし、UTF-8 として不正な場合は Shift_JIS として解釈します
- 1行目はヘッダー、区切りはカンマ、値のエスケープは RFC 4180 に従います
- 複数値項目は JSON 配列（例: `["D-001","D-002"]`）。手入力の利便性のため、JSON 配列でない値は改行区切りとして解釈します
- 表計算ソフトでの数式実行を防ぐため、`= + - @ タブ CR` で始まる値は先頭に `'` を付けて出力し、取り込み時に元に戻します
- 列の順序は自由です。必須列が欠けている場合は取り込めません。未知の列は無視されます
- 追加・更新モードでは、CSV に含まれない列の値は既存データの値が維持されます
- 出力ファイル名は `<種別>_<YYYYMMDD>.csv`

### 取り込みの流れ

1. ファイルを選択（ファイル名からデータ種別を自動判定）
2. 取り込み方法を選択
   - **追加・更新**: 登録済みIDの扱いを「更新／スキップ／エラー」から選択
   - **全件置換**: CSVに含まれないデータを削除（エラー行がある場合は実行不可）
3. プレビューで行ごとの処理内容・エラー・警告（未登録の関連IDなど）を確認
4. 確認ダイアログを経て実行（エラー行は取り込まれません）

列構成を変更する場合は `SCHEMA_VERSION`（`src/lib/schema.ts`）を更新し、保存データの移行処理を `src/lib/store.ts` の `deserialize` に追加します。

## ディレクトリ構成

```
src/
  app/              画面（ルーティング）
  components/       画面コンポーネント（一覧・詳細・フォーム・CSV管理）
  lib/
    schema.ts       データモデル定義
    validate.ts     入力検証・関連ID検証
    csv.ts          CSV パース・生成（汎用）
    csvio.ts        ナレッジ ⇔ CSV 変換、インポート計画
    knowledge.ts    関連付け・参照管理
    search.ts       検索・絞り込み
    store.ts        ブラウザ内保存
    sample.ts       サンプルデータ
```
